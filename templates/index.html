Natural Language Input Dialect: PostgreSQL
"Show total revenue and average order value by product category for Q1 2026"
Generated Production SQL
SELECT c.category_name, COUNT(o.order_id) AS total_orders, ROUND(SUM(oi.price * oi.quantity), 2) AS total_revenue, ROUND(AVG(oi.price * oi.quantity), 2) AS avg_order_value FROM categories c JOIN products p ON c.id = p.category_id JOIN order_items oi ON p.id = oi.product_id JOIN orders o ON oi.order_id = o.order_id GROUP BY c.category_name ORDER BY total_revenue DESC;
